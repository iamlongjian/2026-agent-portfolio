## 二、接口契约（必须完全一致）

### `GET /health`

```json
{ "ok": true, "model": "deepseek-flash" }
```

### `POST /api/chat`

**请求体**

```json
{ "message": "你好", "threadId": "abc-123" }
```

**响应**：`Content-Type: text/event-stream`

**成功时**（逐 token 推送）

```
data: {"content":"你"}
data: {"content":"好"}
data: [DONE]
```

**出错时**

```
data: {"error":"错误信息"}
```

**参数缺失时**：返回 `400` + JSON `{"error":"..."}`（注意：此时**不是** SSE）

4. 怎么让第二轮对话能记得第一轮？——想想 `thread_id`
5. 图有几条边？

> 参考：[Quickstart 精读笔记](../notes/第01周/Quickstart精读笔记.md) 片段 2、3、6

### index.ts

2. `graph.stream()` 的第二个参数里，除了 `thread_id` 还要设置什么，才能拿到逐 token 输出？
3. 流里每一项的结构是什么？怎么从中取出文本？
4. 出错时怎么把错误也通过 SSE 发给前端？

> 参考：[Quickstart 精读笔记](../notes/第01周/Quickstart精读笔记.md) 片段 6

### App.tsx

1. 为什么不能用 `EventSource`？（提示：它只支持 GET）

3. SSE 事件之间用什么分隔？
4. `threadId` 怎么生成、怎么保持不变？
5. 流式追加时怎么只更新最后一条消息？
